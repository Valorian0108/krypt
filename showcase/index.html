how it works
1
Set your limits once. A cap per purchase, a budget per period, and the sellers you trust.
2
Let the agent shop. Small purchases pay themselves, bigger ones wait for you, and anything past your limits is refused.
3
Approve only what needs you. One press, one signature, and the receipt is written.
run the full app

The owner flow stays local.

The hosted page can read and simulate. To sign in, set rules, approve a purchase, or refuse one, run the app on your machine. The login only trusts http://localhost:3000, because that is the one origin the shared FastAuth testnet client redirects back to.

  • 1
    Clone the repo. Everything is public, including the contract and the tests.
  • 2
    Run the contract tests. 45 tests cover caps, budgets, allowlists, approvals, and failures.
  • 3
    Start the app. Copy app/env.example to app/.env and fill in a funded testnet sponsor. The README documents every variable.
  • 4
    Open exactly http://localhost:3000. That origin is the only one the FastAuth testnet client allows.
